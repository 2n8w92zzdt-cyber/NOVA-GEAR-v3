# NOVA GEAR 3.0

An independent, static storefront prototype inspired by the page structure and shopping interactions observed on Glistco.com. NOVA GEAR is a separate concept brand and is not affiliated with Glistco.

## Run locally

Serve the project root with any static web server, for example:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Features

- Responsive homepage, product collection, product detail, search, and information views.
- Working slideshow, collection filtering and sorting, bundle builder, product gallery, and touch-friendly horizontal product/feed rails.
- Demo shopping bag with quantity changes and persistent local browser storage.
- No payment processing, customer accounts, order fulfillment, or newsletter backend is connected.
- Original NOVA GEAR generated imagery; no Glistco logo or product photos are included.

## GitHub Pages

The static site can be published from the repository root or with the included GitHub Actions workflow. All asset URLs are relative to the repository, so the project path `/NOVA-GEAR-v3/` is supported.
